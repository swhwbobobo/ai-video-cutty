# AI Video Cutty

> 看个素材而已，没必要先举行一次剪辑软件启动仪式。

AI Video Cutty 是一个给 AI 视频创作者用的 macOS 本地素材工具。

没有工程，没有素材库，也不准备接管你的工作流。Finder 里选中文件，打开、检查、裁切、压缩，处理完就关掉。

我自己最高频的使用顺序，大概就是下面这样。

### 0. 秒开预览，先看清素材

视频点开就能看，分辨率、帧率、码率、编码、色彩和音频信息直接摆在顶部，缩略图时间轴铺在下面。

哪段有人，哪段黑场，哪里突然换镜头，一眼就能看到。查个素材而已，真的没必要先等达芬奇把全套家当加载完。

### 1. 裁切视频

在时间线上设置 A/B 点，想留哪段就导出哪段。

为了裁几秒素材专门建个剪辑工程，多少有点兴师动众了。

### 2. 裁切画面尺寸

画面四周可以直接裁，旋转、镜像和裁切结果会一起进入导出文件。

横屏改竖屏、去掉多余边缘、救一下奇怪构图，不用在几个软件之间来回倒腾。

### 3. 压缩视频（开发中）

视频压缩正在本地开发，尚未提交到 GitHub，也未包含在当前下载版本中。

想解决的也是一件小事：视频太大，不方便上传、发群或者交付时，填个目标大小，就能直接压缩。

### 4. 压缩图片

图片支持转 JPG，也可以直接填写目标体积。

平台限制 2MB，就让它老老实实压到 2MB 以内，省得手动调质量、导出、查看大小，然后再来一遍。。。

### 5. 逐帧找画面

暂停后用方向键逐帧查看。动作起点、表情变化和穿帮瞬间，不用再靠拖动进度条碰运气。

播放时按住 `←` 或 `→` 可以临时穿梭，松手后恢复原来的速度。熟悉剪辑软件的话，也可以直接用 `J / K / L`，倍速从 `0.5×` 到 `8×`。

### 6. 循环看片段

一句对白、一个动作、一小段音乐，设置 A/B 点后就会自动循环。

终于不用看完一遍，再伸手把进度条拖回去，再看一遍，再拖回去。。。

### 7. 快速跳长视频

`⌘←` 和 `⌘→` 每次前后跳转 5%。

长视频不用从头熬，也不用拿鼠标在一根细线上来回试探人生。

### 8. 截图、旋转和镜像

当前帧可以直接保存为同分辨率 JPG。方向不对就旋转，左右反了就镜像，视频和图片也都支持触控板缩放与拖动查看。

不会出现预览里明明是正的，导出来又躺回去这种血压升高的场面。

### 9. 看波形，导音频

音频波形直接显示，声音位置可以看着找。上下方向键每次调节 10% 音量，`M` 键静音。

容器支持时，还能直接导出原音频轨，不强迫它重新编码。有 A/B 点就导出选段，没有就导出整轨。

### 10. 裁切图片

图片四角可以直接拖动，也能锁定宽高比。处理完可以另存新文件，也可以明确选择覆盖原图。

覆盖是真的覆盖，而且不会自动备份。手速快之前，脑子最好也跟上。

### 11. 快捷键自己改

常用操作都支持重新映射。`⌘S` 固定留给 Finder 服务入口，避免应用内快捷键和 Finder 抢方向盘。

### 只做小事，但把小事做快

AI Video Cutty 不是达芬奇，也不是剪映，更不准备假装自己能替代它们。

重活交给专业剪辑软件。那些每天会遇到几十次、明明很小却特别磨人的素材操作，交给它。

看完，处理完，关掉。

就这么简单。

> AI Video Cutty 由社区维护，与 Apple 或 OpenAI 没有隶属、背书或赞助关系。

## 下载安装

如果你懒得在 Release 页面里翻，终端里复制这一行就行。

```bash
curl -fL https://github.com/swhwbobobo/ai-video-cutty/releases/latest/download/AI-Video-Cutty-macOS.dmg -o "$HOME/Downloads/AI-Video-Cutty-macOS.dmg" && open "$HOME/Downloads/AI-Video-Cutty-macOS.dmg"
```

然后把 `AI Video Cutty.app` 拖进「应用程序」。

因为当前版本使用 ad-hoc 签名，还没有做 Apple 公证，第一次启动时需要按住 `Control` 点按应用，选择「打开」，再确认一次。

普通预览不需要安装任何额外组件。只有精确 A/B 裁切、原码流音频导出和更完整的媒体参数会用到 FFmpeg 或 ffprobe。DMG 里带了可选安装器，你需要时再装，不会偷偷往系统里塞东西。

## 默认快捷键

除 Finder 的 `⌘S` 入口外，下面这些快捷键都可以在 `AI Video Cutty > 设置…` 中修改。

| 操作 | 默认快捷键 |
| --- | --- |
| 播放 / 暂停 | `Space` |
| 关闭预览 | `⌘Q` |
| 后跳 / 前跳 5% | `⌘←` / `⌘→` |
| 倒向穿梭 / 暂停 / 正向穿梭 | `J` / `K` / `L` |
| 设置 A / B 标记 | `I` / `O` |
| 从开头重新播放 | `R` |
| 切换循环 | `P` |
| 清除 A/B 标记 | `X` |
| 静音 / 取消静音 | `M` |
| 重置视频或图像缩放 | `0` |
| 暂停视频时逐帧 | `←` / `→` |
| 播放视频时临时穿梭 | 按住 `←` / `→` |
| 降低 / 提高音量 | `↓` / `↑` |

不带修饰键的方向键专门用于播放控制。播放视频时，松开按住的左右方向键，会恢复之前选择的正向播放速度。

## Finder 服务怎么用

安装并至少启动一次应用后，按下面做。

1. 在 Finder 中选中一个本地媒体文件。
2. 从 `Finder > 服务` 调用「显示 AI Video Cutty」。
3. 如果要设置快捷键，打开 `系统设置 > 键盘 > 键盘快捷键 > 服务`，找到「显示 AI Video Cutty」。

推荐把它设成 `⌘S`，并在 Finder 位于前台时测试。

Finder 服务只接受本地普通文件，并使用第一个符合条件的已选文件。目录、网页 URL 和额外选中的文件不会批量打开。

## 系统要求

- macOS 13 Ventura 或更高版本
- 从源码构建需要 Xcode Command Line Tools
- 需要与 Swift 6 包清单兼容的 Swift 工具链
- 普通预览不需要 FFmpeg
- 精确 A/B 裁切和原码流音频导出需要 FFmpeg
- ffprobe 只用于补充更完整的媒体元数据

## 从源码构建

```bash
git clone https://github.com/swhwbobobo/ai-video-cutty.git
cd ai-video-cutty
swift build -c release
swift test
```

如果 Apple Silicon Mac 的终端正在 Rosetta 或 x86 环境中运行，测试时改用原生架构。

```bash
arch -arm64 swift test
```

构建应用包。

```bash
Scripts/build.sh
```

脚本会重新生成 `build/AI Video Cutty.app`，复制中文使用说明和可选 FFmpeg 安装脚本，生成 `AppIcon.icns`，并执行仅供本地使用的 ad-hoc 签名。

创建可拖入「应用程序」的 DMG。

```bash
Scripts/package_dmg.sh
```

输出文件位于 `dist/AI-Video-Cutty-macOS.dmg`。如果目标 DMG 已存在，脚本会拒绝覆盖。

## 关于 FFmpeg

打开和查看媒体不需要 FFmpeg。

只有当你主动运行 DMG 中的安装器，或者在应用里选择「安装 FFmpeg…」时，下载流程才会开始。它不会静默安装，不使用 Homebrew，不请求 `sudo`，也不会把外部二进制文件塞进应用包。

安装位置是

```text
~/Library/Application Support/AI Video Cutty/bin
```

为了兼容旧版本，如果新目录中没有可用程序，应用还会查询旧目录

```text
~/Library/Application Support/Finder Media Preview/bin
```

新安装不会再写入旧目录。

安装器下载 `ffmpeg-static b6.1.1`，默认使用固定的 npmmirror 地址。只有连接或 HTTP 请求失败时，才会回退到固定的 GitHub 上游发布地址。两个 gzip 文件都必须通过写死的 SHA-256 校验，摘要不匹配会立刻停止。

这套外部运行时采用 `GPL-3.0-or-later` 许可证。准确来源、资源名称、许可证链接和摘要请查看 `THIRD_PARTY_NOTICES.md`。

如果你已经自己安装了 FFmpeg，也可以继续用。重新打开应用后，它会再次检查可执行文件。

## 隐私

预览、编辑、元数据回退和文件保存都在本地完成。

当前代码中没有账号登录、遥测客户端、云上传或远程媒体处理路径。唯一的联网流程，是你主动触发的 FFmpeg 和 ffprobe 下载。

Finder 服务通过 Finder 粘贴板接收所选文件的 URL。自定义快捷键保存在本机用户默认设置中。媒体文件只从本地路径读取，只有在你主动导出或保存时才会写入。

更完整的边界说明请查看 `SECURITY.md`。

## 目前的限制

这项目不装全能，也不藏问题。

- 媒体解码能力取决于当前 macOS 提供的编解码器，不支持的格式可能无法打开
- 一次只打开一个符合条件的 Finder 选中项
- 精确 A/B 裁切会重新编码视频和音频，不是源文件的逐字节复制
- 原码流音频导出的 A/B 边界按音频包对齐，不保证逐采样精确
- 目标容器可能拒绝源音频编解码器
- 图片的「覆盖保存」会替换源文件，而且不会自动备份
- 当前版本使用 ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证

需要保留原图时，请选「另存为新文件」。这句看着像废话，但真覆盖了以后，废话就会突然显得很有价值。。。

少开一次大型软件。

少等一个启动页。

把时间留给真正要剪的东西。
